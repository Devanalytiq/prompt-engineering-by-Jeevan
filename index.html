Introduction to Generative AI & LLMs

What GenAI, LLMs, tokens, context and prompts are

Prompt Fundamentals & Anatomy

Components of a good prompt and prompt structure. The core topic of the session.

Definition

A prompt is an instruction or input provided to an AI model to guide the response you want.

Prompt anatomy

  1. Role
  2. Task
  3. Context
  4. Constraints
  5. Output format

Example

Role: You are an experienced UiPath developer.
Task: Explain REFramework.
Context: The audience has basic RPA knowledge.
Constraints: Use simple language and a practical example.
Output: Give 5 bullet points.

Flow

  1. Role
  2. Task
  3. Context
  4. Constraints
  5. Output format
  6. Better response

Key takeaways

  • Role + Task + Context + Constraints + Output Format is a formula anyone can use immediately.
  • Each missing component is a place where the model has to guess.

Prompting Techniques

Zero-shot, one-shot, few-shot and role prompting

Types

Zero-shotOne-shotFew-shotRole promptingInstruction promptingExample-based prompting

Zero-shot

Classify this email as
Urgent or Normal.

One-shot

Example:
"Server is down" → Urgent

Now classify:
"Password expires tomorrow"

Few-shot

Give 2 to 5 examples before the actual task so the model copies the pattern.

Comparison

  1. Zero-shot: no examples
  2. One-shot: 1 example
  3. Few-shot: multiple examples

RPA real-time example

Classify incoming service-request emails into one of four categories.

Access RequestPassword IssueApplication IssueOther

Key takeaways

  • More examples usually mean more consistent output.
  • Use few-shot when category boundaries are subtle.

Context, Constraints & Instructions

How to control model behavior and improve accuracy

Definition

Relevant context and explicit constraints help the model understand what to do and what not to do.

Concepts

ContextConstraintsPositive instructionsNegative instructionsDelimitersScopeToneAudience

Weak prompt

Summarize this document.

Controlled prompt

Summarize the document in
5 bullet points.

Rules:
- Maximum 100 words
- Use simple English
- Don't add information not
  present in the document

Flow

  1. Raw input
  2. Add context
  3. Add constraints
  4. Add instructions
  5. Controlled output

Key takeaways

  • Say what to do and what to avoid.
  • Use delimiters to separate instructions from the data.

Advanced Prompting & Task Decomposition

Breaking complex tasks into reliable steps

Definition

Complex tasks are divided into smaller, clearly defined tasks to improve reliability and maintainability.

Instead of

Analyze this customer email.

Break it into

1. Identify customer issue
2. Determine category
3. Determine priority
4. Extract important info
5. Recommend action

Flow

  1. Complex task
  2. Break into subtasks
  3. Task 1 → 2 → 3
  4. Combine results
  5. Final output

RPA real-time example: process incoming claims

  1. Email
  2. Extract claim ID
  3. Classify claim
  4. Check priority
  5. Generate summary
  6. Update queue

Key takeaways

  • Small prompts are easier to test, debug and reuse.
  • Each subtask can be validated before the next one runs.
